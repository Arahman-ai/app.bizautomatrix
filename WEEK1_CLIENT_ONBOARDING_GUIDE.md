# Week 1 Client Onboarding Guide

Use this flow for each new client before starting manual SEO or automation work.

## 1. Create Or Confirm Client

- Add the client in the admin panel.
- Confirm business name, website, phone, address, city, industry, and plan.
- For industrial clients, collect product/service categories, target locations, and main inquiry type.

## 2. Run Initial Site Audit

- Go to `Admin -> Site Audit`.
- Select the client.
- Enter the website or product URL.
- Click `Run Full Site Audit`.
- Create the PDF audit report for the client.

## 3. Review SEO Tasks

- Go to `Admin -> SEO Tasks`.
- Load the client tasks.
- Use automated/semi-automated/manual filters.
- Generate fixes for semi-automated tasks before editing the website.
- Mark tasks done only after the website or profile is actually updated.

## 4. Set Up Review Management

- Go to `Admin -> Review Mgmt`.
- Save the client's direct Google review link.
- Click `Generate Review SEO Tasks`.
- Ask the client for recent happy customers before sending review requests.
- Track sent requests, clicks, and open review tasks.

## 5. GBP, Citations, And Competitors

- Use `GBP Audit` to review Google Business Profile setup.
- Use `Citations` to track directory/NAP consistency.
- Use `Competitors` to record who outranks the client and why.

## 6. Industrial Upgrade Plan

For engineering, manufacturing, railway supplier, or industrial automation clients, prepare a first upgrade plan:

- Website structure and product/service catalog.
- Quote request or inquiry workflow.
- WhatsApp, call, and email conversion points.
- SEO pages for products, services, and locations.
- Review/testimonial collection.
- CRM/dashboard for captured leads.
- Optional AI chatbot, documentation assistant, maintenance logs, or project dashboard.

## 7. Report And Next Action

- Use `SEO Report` after the first audit and task review.
- Send the client a short summary: top issues, quick wins, recommended first upgrade, and next 7-day action.
